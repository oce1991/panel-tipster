Paso 1 Conecta tu base de datos

Este panel guarda tus datos en tu propio proyecto de Supabase (gratuito) para que se sincronicen entre PC y móvil. Solo hace falta hacerlo una vez.

  1. Crea una cuenta gratis en supabase.com y un proyecto nuevo.
  2. En el proyecto, ve a SQL Editor y ejecuta esto una vez: 
    create table tipster_data (
  id text primary key,
  data jsonb,
  updated_at timestamptz default now()
);
alter table tipster_data enable row level security;
create policy "public read" on tipster_data for select using (true);
create policy "public write" on tipster_data for insert with check (true);
create policy "public update" on tipster_data for update using (true);
  3. Ve a Project Settings → API y copia la "Project URL" y la clave "anon public" aquí abajo.

Nota: con esta configuración simple, cualquiera con tu URL y clave podría leer o escribir tus datos. Para uso personal es un riesgo bajo (no hay contraseñas ni datos bancarios), pero no compartas esa clave públicamente.

Auto Importar temporada (CSV)

Sube el CSV de una temporada y calculamos las medias de córners y goles por equipo, casa/fuera, automáticamente. Se fusiona con lo que ya tengas guardado (media ponderada por partidos).

Dónde conseguirlo: Primera/Segunda → football-data.co.uk (columnas HomeTeam, AwayTeam, FTHG, FTAG, HC, AC). 1ª RFEF Grupo 1 → footystats.org/es/spain/primera-division-rfef-group-1 (botón "Descargar datos en CSV"). Cualquier CSV con esas columnas (en inglés o español) sirve.

Si vuelves a subir el CSV de una temporada que ya tenías (mismo nombre de liga + temporada), se sustituye automáticamente — nunca se suma encima. Así puedes resubir la 25/26 cada semana sin duplicar nada.

Masivo Importar fichas de equipo (Excel/CSV)

Para cargar de golpe las medias de córners y goles de todos los equipos de una liga (por ejemplo, transcritas de otra web). Columnas esperadas en la primera fila: Equipo, CF Casa, CA Casa, CF Fuera, CA Fuera, GF Casa, GA Casa, GF Fuera, GA Fuera (si el archivo trae una columna "Liga" por fila, se usa esa; si no, se aplica la liga que elijas abajo a todas las filas). Si un equipo ya existe con ese nombre en esa liga, se sustituye su ficha entera — no se promedia con lo anterior.

Modelo Córners — Poisson

λ_local = media(córners a favor del local en casa, córners en contra del visitante fuera) — y análogo para el visitante. Se suman para el total del partido.

Modelo Goles y 1X2 — Poisson bivariante simplificado

λ_local = media(goles a favor local en casa, goles en contra visitante fuera). Matriz de resultados 0–6 goles por equipo.

Calendario Importar jornadas (Excel/CSV)

Crea un Excel con estas columnas exactas en la primera fila: Liga, Jornada, Fecha, Local, Visitante. Una fila por partido, para toda la temporada o solo las próximas jornadas. Al importar una liga, se sustituye todo su calendario anterior (para actualizar fechas o resultados de fixture, vuelve a subir el archivo entero de esa liga).
